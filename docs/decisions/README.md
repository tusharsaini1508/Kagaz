# Decision records

One file per real decision. Short is fine, one page is plenty.

Copy `0000-template.md`, number it in sequence, and name it after the decision,
for example `0001-which-ai-reads-scanned-pages.md`.

Write one whenever we chose between real options and a reasonable person could
have chosen differently. Skip it for obvious calls.

- Which AI reads scanned pages.
